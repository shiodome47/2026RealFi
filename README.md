# Cardano セッションのアーカイブ

Cardano まわりの録音・録画の文字起こしから、1 回につき 1 セットの HTML を作って残していくリポジトリ。

中心は RealFi のコミュニティコール（Office Hours）ですが、Cardano エコシステムの公開されたセッションも同じ形式で扱っています。

> **回によって扱いが違います**
>
> | 種別 | 扱い |
> | --- | --- |
> | **RealFi Office Hours** | **チャタムハウスルール。**内容は共有しますが、**発言者の氏名は記載しません**。実名・ハンドル名・ステークプール名はどのファイルにも残さず、`進行役` / `登壇者A・B・C` / `参加者A〜L` という仮のラベルだけを使っています |
> | **Cardano（公開録画）** | YouTube などで公開されている録画。チャタムハウスルールの対象ではないため、**発言者は実名のまま**扱います。固有名詞の明らかな誤変換は修正しています |
>
> どちらかは `episodes/<slug>/meta.yml` の `chatham_house_rule` で決まります。`tools/check.py` の実名チェックもこのフラグで切り替わります。

## 各回に 3 つのページ

| ページ | 中身 |
| --- | --- |
| `index.html` | **メイン。** 内容を話題ごとに再構成したまとめ。**日本語と英語の両方**。図解つき |
| `transcript-ja.html` | 日本語全文 |
| `transcript-en.html` | 英語全文（音声認識の出力そのまま。匿名化、または固有名詞の誤変換の修正のみ実施） |
| `standalone.html` | 上記 3 つを 1 ファイルにまとめたもの。外部参照なし |

まとめだけ読めば概要はつかめる。正確性を確認したいときのために全文を併置している。

## ディレクトリ

```
├── CLAUDE.md          新しい回を追加する手順（Claude が読む）
├── episodes/          原本。匿名化した文字起こしを保存する
│   └── YYYY-MM-DD-<slug>/
│       ├── meta.yml
│       └── transcript.txt
├── shared/            回をまたぐ資産
│   ├── glossary.md         用語の統一表記・誤変換の修正表・翻訳方針
│   ├── speakers.md         匿名化のルール・話者推定の確度
│   └── open-questions.md   保留になった質問の追跡
└── docs/              公開する成果物（GitHub Pages のルート）
    ├── index.html          全回の一覧
    ├── assets/style.css
    └── YYYY-MM-DD-<slug>/
```

`episodes/` と `docs/` を分けているのは、**フォーマットを変えたくなったときに何度でも作り直せるようにするため**。

`shared/` は回数が増えたときに効く。音声認識は毎回同じ固有名詞を同じように間違えるし、保留になった質問は次回以降に回収されることが多い。

## 新しい回を追加する

文字起こしを Claude に渡して「HTML を作って」と伝えるだけ。手順と毎回の完成条件は `CLAUDE.md` に書いてある。

生成したら検証を流す。

```
python3 tools/check.py
```

匿名化の漏れ、リンク切れ、id の重複、英日の全文のズレ、テーマ非対応の色などをまとめて見る。

## 公開

GitHub Pages の公開元を **`docs/`** にすれば公開できる。設定は Settings → Pages → Build and deployment → Source: `Deploy from a branch` → Branch: このブランチ + `/docs`。

## 注意点

- 現在の文字起こしには**話者ラベルもタイムスタンプもない**ため、話者は文脈から推定している。推定が不確かな箇所は各ページに `(推定)` と表示し、`shared/speakers.md` に根拠を記録している
- まとめページで <kbd>補足</kbd> のマークが付いた記述は、理解を助けるために足したもので、**コール中の発言ではない**
- ページはライト・ダーク両方に対応している。OS の設定に自動で追従し、右上のボタンで手動切り替えもできる（選択は保存される）
- **まとめは日本語と英語の両方で読める。**初回訪問時はブラウザの言語設定で自動判定し、右上のボタンで切り替えられる（選択は保存される）
