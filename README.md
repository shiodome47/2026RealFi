# RealFi Office Hours アーカイブ

RealFi のコミュニティコール（Office Hours）の録音から、1 回につき 1 セットの HTML を作って残していくリポジトリ。

## 各回に 3 つのページ

| ページ | 中身 |
| --- | --- |
| `index.html` | **メイン。** 内容を話題ごとに再構成した日本語のまとめ |
| `transcript-ja.html` | 日本語全文 |
| `transcript-en.html` | 英語全文（音声認識の出力そのまま、未編集） |

まとめだけ読めば概要はつかめる。正確性を確認したいときのために全文を併置している。

## ディレクトリ

```
├── CLAUDE.md          新しい回を追加する手順（Claude が読む）
├── episodes/          原本。文字起こしを無加工で保存する
│   └── YYYY-MM-DD-<slug>/
│       ├── meta.yml
│       └── transcript.txt
├── shared/            回をまたぐ資産
│   ├── glossary.md         用語の統一表記・誤変換の修正表・翻訳方針
│   ├── people.md           話者と質問者の一覧・表記ゆれ・話者推定の根拠
│   └── open-questions.md   保留になった質問の追跡
└── docs/              公開する成果物（GitHub Pages のルート）
    ├── index.html          全回の一覧
    ├── assets/style.css
    └── YYYY-MM-DD-<slug>/
```

`episodes/` と `docs/` を分けているのは、**フォーマットを変えたくなったときに何度でも作り直せるようにするため**。原本は加工せずに残す。

`shared/` は回数が増えたときに効く。音声認識は毎回同じ固有名詞を同じように間違えるし、保留になった質問は次回以降に回収されることが多い。

## 新しい回を追加する

文字起こしを Claude に渡して「HTML を作って」と伝えるだけ。手順は `CLAUDE.md` に書いてある。

## 公開

GitHub Pages の公開元を `docs/` にすれば公開できる。`episodes/` は Pages では配信されないので、生の文字起こしがそのまま出ることはない。

## 注意点

現在の文字起こしには**話者ラベルもタイムスタンプもない**ため、話者は文脈から推定している。推定であることは各ページに明記し、根拠の弱い箇所は `shared/people.md` に記録している。録音ツール側で話者分離（diarization）の出力が取れるなら、そちらを使ったほうが精度は上がる。
