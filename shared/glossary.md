**公開録画の回（`chatham_house_rule: false`）では実名を残す。**この場合、人名も含めて**固有名詞の明らかな誤変換は修正する**。

## プロダクト用語

| 用語 | 説明 | 訳し方 |
| --- | --- | --- |
| **USDR** | RealFi のステーブルコイン。常に 1 USDR = 1 USD | 訳さない |
| **sUSDR** | USDR をステークすると受け取るトークン。**ステーブルコインではない**。価値が変動し、その差分が利回りになる。ファンジブルで、個々のトークンに日付やレートは埋め込まれていない | 訳さない |
| **staking / unstaking** | USDR ↔ sUSDR の交換。公式レート（official rate）で行われ、レートは常に公開される | ステーク / アンステーク |
| **bridge** | 他チェーンとの接続。burn-and-mint ではなく、EVM 側でもネイティブな体験を提供しつつ Cardano を source of truth に置く設計 | ブリッジ |
| **hub and spokes** | ブリッジの構成。Cardano がハブ（中心・唯一の権威）、他チェーンがスポーク | ハブ&スポーク |
| **source of truth** | 会計とステーキングの正となる場所。RealFi では Cardano | 正となる台帳 |
| **one-click flows** | 複数プロトコルをまたぐ複数トランザクションを、ユーザーの署名1回で実行する仕組み | ワンクリックフロー |
| **looping strategy** | 借入と再投資を繰り返してレバレッジをかける DeFi の運用手法 | ルーピング戦略 |
| **governance token** | 未発行。来年前半予定 | ガバナンストークン |
| **SDK** | 外部開発者向け。一部はオープンソース化予定（バックログ） | 訳さない |
| **transparency portal** | 資金の投資先を公開するポータル。ウェブサイト上にある | 透明性ポータル |
| **private credit** | RealFi の裏付け資産。ノンバンクによる融資 | プライベートクレジット |
| **banking the unbanked** | RealFi のミッション。銀行口座を持てない層に金融アクセスを届ける | 訳さず注釈をつける |
| **anti-farming** | エアドロップ狙いの不正な複数ウォレット運用を検知・遮断する仕組み | アンチファーミング |
| **depeg** | ステーブルコインが 1 ドルの固定を外れること | デペグ |
| **TVL** | Total Value Locked。プロトコルに預けられている資産の総額 | 訳さない |
| **peg stability module（PSM）** | USDR を 1 ドルに保つために常時動く仕組み | ペッグ安定化モジュール |
| **stability fund** | ペッグ維持のために RealFi 自身が運用する資金 | 安定化ファンド |
| **loss waterfall（損失のウォーターフォール）** | 損失が及ぶ順序。RealFi では ①エクイティ・バッファ → ②プロトコルの安定化ファンド → ③sUSDR の切り下げ → ④USDR 保有者（2026-08-14 の回で初めて示された）。**手前 2 段の金額は未開示**で、②は「初日には存在しない」と明言されている。**順序を書くときは、各段の厚みが示されたかどうかも必ず添える** | 損失のウォーターフォール |
| **equity buffer（エクイティ・バッファ）** | 損失を最初に受け止めるために別途調達される資本。**RealFi では「調達した」と「これから調達する」の両方の言い方が同じ説明の中に出ており、ローンチ時に満額あるかは確定していない** | エクイティ・バッファ |
| **hardening** | 本番と同じ経路を**実際のお金で通す**段階。testnet との違いは、失敗すると本当に損が出ること。RealFi は 10 万ドルで実施 | 訳さない・注釈をつける |
| **TradFi** | traditional finance。銀行・証券・取引所・規制当局といった、**crypto より前からある金融の世界**。DeFi と対にして使う。**書類と審査と人の判断で進むため、コードのように並行させられない**点が、mainnet の遅れの説明で繰り返し出る | 訳さない・初出で「伝統的な金融」と補う |
| **LayerZero** | **チェーン間でメッセージを運ぶ土台**。ブリッジより 1 つ下の層で、トークンの移動はその上の使い方の 1 つにすぎない。RealFi は CCTP のフォークからの**移行先**として挙げ、「メッセージングの層を差し替えやすいように設計してある」と述べている。**到着時期は「年末に向けて来ると理解している」という伝聞まで**（2026-08-14）。2026-07-26 の回では「Q3 ローンチ目標、EUTXO なので単純移植ではない」 | 訳さない |
| **boring / boringly（話者の口ぐせ）** | 2026-08-14 の CEO が、**地味だがすでに枯れていて効くもの**を指すときに使う前置き。hardening の紹介（quite boringly called hardening）と、第三者評価の説明（to be quite boring about it, it's what traditional TradFi does）の 2 箇所。**謙遜であって軽視ではない**ので、「退屈な」とだけ訳すと逆の印象になる | 文脈を補って訳す |
| **CCTP** | Circle の Cross-Chain Transfer Protocol。**ロックせず、片方で burn して片方で mint する**ため、資産をロックした金庫（honeypot）を作らずに済む。RealFi は現在このフォークを使い、LayerZero が Cardano に来たら移行する予定 | 訳さない |
| **ticker（ティッカー）** | 取引所や取引画面で銘柄を指す**短い記号**。**トークンそのものとは別物**なので、「ティッカーを変えてもプロトコルは何も変わらない」が成り立つ | 訳さない・初出で「ティッカー（記号）」と補う |
| **crew / district** | 2026-08-24 に提示されたアンバサダー制度の二層。**crew は問題を解くために集まり、解けたら解散する集まり**。**district は恒久的な場所**で、手法とプレイブックが貯まる。district の例として harbor（地域ハブ）／ stage（発信）／ bazaar（GTM と提携）／ forge（プロダクト）／ dark forest（届きにくい場所）が挙がった。**名前はコミュニティに付けてもらう方向** | 訳さない |
| **L1 / L2（指標の階層）** | **ブロックチェーンのレイヤー 1 / 2 ではない。**2026-08-24 で、**L1 は事業全体の成果を表す数値**（TVL、ペッグの安定、プロトコルの利益、月間アクティブウォレット、利回りのスプレッド）、**L2 はその下でそれを押し上げる数値**（検索シェア、ウォレット、資本の粘着性）として使われた。**Cardano の文脈では必ず誤読されるので、初出で必ず断る** | 訳さない・必ず注釈をつける |
| **guardrail（ガードレール）** | **目標値ではなく幅**。上げるほど良い数字ではなく、範囲から出ないでほしい数字。過剰担保率、プロトコルの流動性カバー率、ステーキング比率、リスク・コンプライアンスのスコアが挙がった | ガードレール |
| **handshake（握手）** | 2026-08-24 で繰り返された言い方。**コミュニティ／SPO の側と、事業の側の接点**。両側が価値を得ている状態を指す | 握手（原語を添える） |

| **proof of human** | SPO はオンチェーンでもオンラインでも影響力があるため、**その活動が本物の人間によるものだと高い確度で見て取れる**、という主張で使われた。**「確度が上がる」という言い方で、判定方法は説明されていない**（open-questions 項目 21） | 訳さない |

| **two-book system（2 ブック制）** | 資産のプールは 1 つのまま、**帳簿を 2 つに分ける**やり方。**ブック 1** はステークしていない USDR（いつでも出られる側）、**ブック 2** は sUSDR（7 日のクールダウンがある側）。**出ていける速さが違うので、置ける資産が違う** | 訳さない・「2 ブック制」と併記 |

## 翻訳の方針

- **プロダクト用語・チェーン名・組織名は訳さない**（USDR, sUSDR, Cardano, EVM, DEX, SDK, testnet, mainnet など）
- **外部プロトコルに URL を張るときは公式ドメインを毎回確認する。**DeFi のプロトコルは偽サイトが多く、ドメインを 1 文字間違えるだけで読者を危険な場所に送ることになる。**うろ覚えで張らない。**このリポジトリで使っている先はこの表に載せてあるので、追加するときもここに記録する
- **testnet / mainnet** はそのまま。「テストネット」「メインネット」でもよいが1本の中では統一する
- 話者の発言は「ですます調」で訳す。口語のフィラー（you know, I mean, like）は落とす
- 断定していない発言（"I think", "probably", "we haven't landed on"）は**日本語でも断定しない**。ロードマップや時期の話で特に重要
