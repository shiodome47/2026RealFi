# 話者ラベルと匿名化のルール

## まず、その回が匿名化の対象かを確認する

**回ごとに扱いが違う。**`episodes/<slug>/meta.yml` の `chatham_house_rule` を見て決める。

| 値 | 対象 | 扱い |
| --- | --- | --- |
| `true` | RealFi Office Hours などのコミュニティコール | **実名を一切残さない。**ラベルに置換する |
| `false` | 公開されている録画（YouTube など） | **実名のまま扱う。**固有名詞の誤変換は修正する |

`tools/check.py` の実名チェックもこのフラグで切り替わる。`NAMES` は回ごとの辞書で、`true` の回のファイルだけをその回の名前で検索する。**名前は回をまたぐと普通の単語や、まったく別の実在の人物の名前になりうる**（ある回で匿名化した短いファーストネームが、別の回では公開の場で名前を出されている第三者を指している、ということが起きる）ため、全体を一括で検索してはいけない。

`shared/` や `README.md`、`docs/index.html` のような回をまたぐファイルは、**すべての回の名前**で検索される。

## チャタムハウスルール（`chatham_house_rule: true` の回）

内容は共有してよいが、**誰が発言したかは記載しない**。

そのため、リポジトリ内のどのファイルにも実名を残さない。`episodes/` に置く文字起こしも匿名化した状態で保存する（このリポジトリは Public のため）。

## ラベルの付け方

回ごとに独立して振る。**回をまたいで同じ人物に同じラベルを割り当てない**（複数回を突き合わせると識別できてしまうため）。

| ラベル | 対象 |
| --- | --- |
| `進行役` / `Host` | 司会・進行 |
| `登壇者A` `登壇者B` `登壇者C` … / `Speaker A` `B` `C` | 登壇したチームメンバー。登場順に A から振る |
| `参加者A` `参加者B` … / `Participant A` `B` … | チャットで質問したコミュニティメンバー。登場順に A から振る |
| `プロダクト担当` `treasury チーム` `法務チーム` | 質問が回された先。実名は使わない |

## 匿名化のチェックリスト

生成後、以下がリポジトリ内に残っていないか必ず確認する。

- [ ] **氏名**（登壇者・コミュニティ参加者の両方）
- [ ] **ハンドル名**（Discord の表示名など）
- [ ] **ステークプール名・所属組織名**（個人と結びつくもの）
- [ ] **発言の中で呼びかけられた名前**（"Thanks, ○○" のような箇所も置換する）

置換の抜けは、以下のようなコマンドで機械的に確認できる。

```
grep -rniE '名前1|名前2|名前3' --include='*.html' --include='*.md' --include='*.txt' --include='*.yml' .
```

**残してよいもの** — 組織名・プロダクト名（RealFi, Cardano, Sundae, TxPipe, Liqwid, Midnight, Rosen Bridge, IO など）は発言者の識別につながらないので、そのまま使う。

## 話者推定について

現在の文字起こしには**話者ラベルもタイムスタンプもない**ため、話者は文脈から推定している。推定に留まる箇所には、全文ページ上で `(推定)` / `(inferred)` を付ける。

匿名化しているので推定を外しても実害は小さいが、**発言の帰属が変わると内容の読み方が変わる**箇所（例：技術的な断定をしたのが誰か、保留を判断したのが誰か）は慎重に扱う。

録音ツール側で話者分離（diarization）の出力が取得できるなら、そちらを使ったほうが精度は上がる。その場合も、実名ではなくラベルに置き換えてから保存する。

## 2026-07-24 エンジニアリング回 — 推定の確度

**確度が高い箇所** — 進行役（進行・質問読み上げ）、登壇者B（ブリッジと USDR/sUSDR の技術説明）、登壇者A（チーム・パートナー・運用）、登壇者C（SDK）。発言内容と担当領域が一貫しており、他の話者が言う内容ではない。

**推定に留まる箇所**

1. **「モチベーション」パートの 2 人目**（"For me, two things. I think one is it's pretty unique in Cardano…"）
   登壇者A の回答の直後に入る発言。この直後に進行役が改めて同じ質問を振っており、順序が不自然。回線の遅延で発言が重なった可能性がある。登壇者B と推定したが、登壇者C の可能性も残る。

2. **メインネットのローンチ日への回答**（"I think [Speaker A] can probably speak to that a bit better…"）
   「登壇者A のほうが詳しい」と言っているので登壇者A ではない。登壇者B か登壇者C。言い回しから登壇者C と推定。

3. **短い相槌**（"Yeah, sorry, go on." "100%, yeah." など）
   ほぼ判別不能。前後の文脈から最も自然な話者を当てている。

4. **treasury チームへの転送を提案した発言**
   登壇者A と推定。登壇者B の可能性もある。

| Eric | ホスト。AlphaGrowth |

**推定に留まる箇所**

## 2026-08-06 GTM 回 — チャタムハウスルール（公式録音）

**この回は原本が公式の録音である。**話者ラベル（進行役の実名と、`Speaker 2` `Speaker 3` という連番）とタイムスタンプが元から付いていたため、**話者の推定を一切していない**。全文ページに `(推定)` / `(inferred)` は 1 つも付けていない。

| ラベル | 対象 |
| --- | --- |
| `進行役` / `Host` | 司会。SPO プログラムの説明とチャットの読み上げ |
| `登壇者A` / `Speaker A` | go-to-market 担当。原本では 3 つの綴りに分かれていたが、内容から同一人物なので 1 つに寄せた |
| `参加者A〜C` / `Participant A–C` | チャットで質問したコミュニティメンバー（登場順） |

**この回で特に注意した点**

1. **経歴が長く語られている。**勤務先・学校名・出向先を並べると個人が特定できるため、**すべて業種の記述に置き換えた**（例: 具体的な投資銀行名 →「大手の投資銀行」、特定のレイヤー 2 の名前 →「新興国市場に注力するレイヤー 2」）。年次と職務内容はそのまま残している。置き換えた語は `tools/check.py` の `NAMES` に登録済み。

2. **第三者の実名も役割に置き換えている。**この回では Cardano の創業者の名前が挙がるが、**チャタムハウスルールの回で下の名前だけが出ると参加者と見分けがつかない**ため、「Cardano の創業者」と書いている。同僚も「データチームの人」「投資チームの 2 人」「コミュニティ団体の方」のように役割で書いた。

3. **冒頭のロールコール**（進行役が参加者のハンドル名を読み上げる箇所）は、ハンドル名を記載せず `[参加者の呼びかけ。ハンドル名は記載しない]` に置き換えている。

## 2026-08-11 Masumi — 匿名化の対象（登録制・録画は非公開）

**判断の根拠** — 登録制のコールで、**録画は一般に公開されていない**（参加者およそ 50 名）。公開録画の回ではないので実名は残さない。「公開されていないかもしれない」という不確かな状態だったため、**迷ったら匿名化する側に倒す**という方針に従った。公開されていることが確認できれば実名に戻せるが、**逆はできない**（このリポジトリは Public）。

| ラベル | 対象 |
| --- | --- |
| `進行役` / `Host` | 主催。Masumi 側。ニュース紹介とプロダクトのデモ |
| `登壇者A` / `Speaker A` | ゲスト。エージェント × ブロックチェーンの調査を発表 |
| `参加者A〜F` / `Participant A–F` | 発言・チャットで参加したコミュニティメンバー（登場順） |

**この回で特に注意した点**

1. **所属と役職の両方が名乗られている。**「◯◯社の△△チームのプロダクトリード」のように**並べると個人が特定できる**ため、勤務先も担当プロダクトも**領域の記述に置き換えた**（例: 「Cardano の中核開発企業でプロダクト側の仕事をしています」）。技術名そのもの（Hydra など）は公開されているものなので、**議論の対象として出てくる分は残している**。置き換えた語は `tools/check.py` の NAMES に登録済み。

2. **第三者の実名も役割に置き換えた。**Cardano の創業者と、ある企業の創業者の名前が挙がるが、**チャタムハウスの回で人名が混ざると参加者と見分けがつかない**ため、それぞれ「Cardano の創業者」「Twitter の創業者」としている。**組織名・プロダクト名は残す**（Cloudflare、Stripe、Base、Solana、NEAR、IOTA、Block など）。話の対象であって発言者ではないため。

3. **名前の綴りについてのやり取りを丸ごと落とした。**冒頭でゲストの名前の綴りについて短いやり取りがあるが、**内容が名前そのものなので、置換ではなく削除**して `[名前の綴りについての短いやり取り。ここでは記載しない]` に置き換えた。

4. **話者ラベルもタイムスタンプもない原本。**話者は文脈からの推定だが、**声が実質 2 つしかない区間が大半**なので確度は高い。`(推定)` を付けたのは**冒頭のマイク確認 3 発話と、短い相槌 1 か所だけ**。全体に付けると印の意味がなくなるため。

5. **エージェント名（Hannah、Elena、Alex、Noodles）は人名ではない**ので残している。デモに出てくる AI エージェントの名前。
