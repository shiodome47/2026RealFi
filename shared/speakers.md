# 話者ラベルと匿名化のルール

## チャタムハウスルール

このアーカイブが扱うコールは**チャタムハウスルール**で運用されている。内容は共有してよいが、**誰が発言したかは記載しない**。

そのため、リポジトリ内のどのファイルにも実名を残さない。`episodes/` に置く文字起こしも匿名化した状態で保存する（このリポジトリは Public のため）。

## ラベルの付け方

回ごとに独立して振る。**回をまたいで同じ人物に同じラベルを割り当てない**（複数回を突き合わせると識別できてしまうため）。

| ラベル | 対象 |
| --- | --- |
| `進行役` / `Host` | 司会・進行 |
| `登壇者A` `登壇者B` `登壇者C` … / `Speaker A` `B` `C` | 登壇したチームメンバー。登場順に A から振る |
| `参加者A` `参加者B` … / `Participant A` `B` … | チャットで質問したコミュニティメンバー。登場順に A から振る |
| `プロダクト担当` `treasury チーム` `法務チーム` | 質問が回された先。実名は使わない |

## 匿名化のチェックリスト

生成後、以下がリポジトリ内に残っていないか必ず確認する。

- [ ] **氏名**（登壇者・コミュニティ参加者の両方）
- [ ] **ハンドル名**（Discord の表示名など）
- [ ] **ステークプール名・所属組織名**（個人と結びつくもの）
- [ ] **発言の中で呼びかけられた名前**（"Thanks, ○○" のような箇所も置換する）

置換の抜けは、以下のようなコマンドで機械的に確認できる。

```
grep -rniE '名前1|名前2|名前3' --include='*.html' --include='*.md' --include='*.txt' --include='*.yml' .
```

**残してよいもの** — 組織名・プロダクト名（RealFi, Cardano, Sundae, TxPipe, Liqwid, Midnight, Rosen Bridge, IO など）は発言者の識別につながらないので、そのまま使う。

## 話者推定について

現在の文字起こしには**話者ラベルもタイムスタンプもない**ため、話者は文脈から推定している。推定に留まる箇所には、全文ページ上で `(推定)` / `(inferred)` を付ける。

匿名化しているので推定を外しても実害は小さいが、**発言の帰属が変わると内容の読み方が変わる**箇所（例：技術的な断定をしたのが誰か、保留を判断したのが誰か）は慎重に扱う。

録音ツール側で話者分離（diarization）の出力が取得できるなら、そちらを使ったほうが精度は上がる。その場合も、実名ではなくラベルに置き換えてから保存する。

**推定に留まる箇所**

1. **「モチベーション」パートの 2 人目**（"For me, two things. I think one is it's pretty unique in Cardano…"）

2. **メインネットのローンチ日への回答**（"I think [Speaker A] can probably speak to that a bit better…"）
   「登壇者A のほうが詳しい」と言っているので登壇者A ではない。登壇者B か登壇者C。言い回しから登壇者C と推定。

3. **短い相槌**（"Yeah, sorry, go on." "100%, yeah." など）
   ほぼ判別不能。前後の文脈から最も自然な話者を当てている。

4. **treasury チームへの転送を提案した発言**
   登壇者A と推定。登壇者B の可能性もある。
