エンジニアリング回 — ブリッジ、ワンクリックフロー、そしてプラットフォーム構想

2026-07-24 · Discord · 参加者 30〜35名

RealFi は、Cardano 上で利回り商品を作るだけでなく、他の開発者や他チェーンからも使える「金融インフラ」になろうとしている。プロトコルは testnet で稼働中。Cardano をハブに据えたクロスチェーン構想、複数プロトコルを署名 1 回でつなぐワンクリックフロー、USDR と sUSDR の違い、そして外部開発者向け SDK について。

各回のページには「まとめ（日本語）」「日本語全文」「英語全文（原文）」の 3 つがあります。
文字起こしの原本は episodes/、用語集と持ち帰り質問の追跡は shared/ にあります。
